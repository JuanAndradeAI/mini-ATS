# Mini ATS — Requirements

## Goal

Build a simple Applicant Tracking System that can be deployed and used by a first customer as quickly as possible.

## Core requirements

- REQ-01: An admin can create customer accounts.
- REQ-02: An admin can create other admin accounts.
- REQ-03: A customer can log in.
- REQ-04: A customer can create jobs.
- REQ-05: A customer can add candidates with basic profile information, including a LinkedIn URL.
- REQ-06: A customer can view candidates in a compact Kanban board.
- REQ-07: A customer can filter the Kanban board by job.
- REQ-08: A customer can filter candidates by candidate name.
- REQ-09: An admin can perform the same actions as a customer on their behalf.

## Technical requirements

- TECH-01: Supabase will be used as the backend.
- TECH-02: Supabase Authentication will be used for user authentication.
- TECH-03: Supabase PostgreSQL will store application data.
- TECH-04: The application must be deployable and accessible online.
- TECH-05: The source code will be available in a public GitHub repository.

## Optional / stretch goal

- AI-01: Add a simple AI-assisted candidate CV assessment feature.
- AI-02: If the AI feature is not implemented, document and explain how it would be implemented.

## Delivery

- Admin login credentials.
- Live application link.
- Public GitHub repository.
- 5-minute demo video.
- Documented assumptions.
